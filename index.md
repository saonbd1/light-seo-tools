# SEO Tools

Welcome to the SEO Tools site. This site offers quick browser-side helpers and accepts requests for advanced Scrapebox-backed reports.

Quick tools available on this site:

- Duplicate URL Finder
- Meta Tag Generator
- Keyword Generator
- Internal/External Link Checker

For advanced reports (deep scraping, bulk analysis), submit a request via the Request a Report page. Reports are processed offline using Scrapebox and delivered to you via email or a private download link.


## How it works

1. Submit a report request with your domain or URL list.
2. The site notifies the admin.
3. Scrapebox (running on the admin PC) processes the request and exports reports.
4. The admin uploads the report and the site sends a download link to the user.
