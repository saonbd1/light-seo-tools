# Tools Overview

This folder contains individual pages for each tool. Active tools are lightweight browser-side helpers.

## Implemented Browser Helpers (Free)

- Duplicate URL Finder - Remove repeated URL entries locally in your browser
- Meta Tag Generator - Generate basic title and description tags for HTML
- Link Extractor - Extract internal URLs from a starting page up to three crawl levels deep
- Redirect Checker - Check URLs for 301, 302, and other redirect status codes instantly
- Robots.txt Checker & Generator - Inspect a site's robots.txt and generate custom directives
- Anchor Text Checker - Extract anchor text and target URLs from page HTML
- Article Scraper - Pull readable text out of a page's HTML
- Bing Meta Scraper - Extract title and meta tags from HTML
- Bing Image Grabber - Collect image URLs from page HTML
- Dofollow Link Tester - Detect dofollow vs nofollow links
- Outbound Link Checker - Find external links in a page's HTML
- Merge Duplicate Links - Merge two URL lists and remove duplicates
- Sitemap Scraper - Fetch a sitemap.xml and extract its URLs
- Alive URL Checker - Check which URLs are still reachable
- Bandwidth Meter - Estimate the download size of a URL
- OCR Image to Text - Convert image to text using client-side optical character recognition
- Trim URL to Domain - Strip URLs down to their domain
- Trim URL to Root - Strip URLs down to their origin
- Trim URL to First Folder - Keep the origin plus the first path segment
- Name Generator - Generate random names for placeholder data
- Email Generator - Generate random email addresses
- Bulk Anchor Text Creator - Generate HTML anchors from URLs and text
- Remove Duplicate Entries - Deduplicate any text list
- Split Text File - Break a list into smaller parts
- Sort Text Files - Sort lines alphabetically or numerically
- Extract URL Links - Pull all URLs from text or HTML
- Legal Page Generator - Generate Terms, Privacy Policy, and Affiliate Disclosure text

Legacy report workflow URLs are retained as noindex retirement notices; they are not active tools.
