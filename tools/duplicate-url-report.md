# Duplicate URL Report

Upload or submit a plain-text URL list for processing with Scrapebox. Scrapebox removes repeated entries and returns the cleaned unique URL list.

## Workflow preview

1. Submit a `.txt` file with one URL per line.
2. Scrapebox removes duplicate entries.
3. The result is exported as HTML, TXT, CSV, or XLSX.
4. The completed report is delivered using a private download link.

## Example result

```text
http://example.com/page1
http://example.com/page2
http://example.com/page3
```

This preview shows the cleaned unique URLs that the customer receives. The original input count and unique count are recorded in the admin sheet.
