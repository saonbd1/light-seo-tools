# Meta Tag Scraper Report

Submit a plain-text URL list for offline Scrapebox Page Analyzer processing. The report extracts page metadata for each URL.

## Workflow preview

1. Submit a `.txt` file with one URL per line.
2. Scrapebox analyzes the pages.
3. The result is exported as HTML, TXT, CSV, or XLSX.
4. The completed report is delivered using a private download link.

## Example CSV result

```csv
Url,Title,Description
http://example.com/,Example Domain,
```

An empty Description field is valid when the page has no meta description.
